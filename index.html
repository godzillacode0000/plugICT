Do I need to be technical to set this up?

You’ll need a compatible AI agent that can run local commands. The setup guide walks you through the repo, your private license file, and the search checks. Setup handles the vault download and verification; MCP configuration is optional.

Which AI agents can I use?

PlugICT is built for Hermes and similar terminal-capable agents that can run local Python commands and read JSON. The default path uses plugict_search.py. MCP is optional for compatible clients. A normal browser chat by itself cannot reach your local vault.

Does everything work offline?

The vault’s search runs locally. A cloud AI model and the linked YouTube lessons need internet access. If your agent uses a cloud provider, your question and retrieved excerpts may be sent to that provider.

What do I receive after purchase?

A private license.key, delivered within 24 hours. Use it with the public PlugICT repository; setup downloads and verifies the encrypted vault. Keep your license private and give setup the local file path, not a publicly shared key.

Are there any other costs?

PlugICT costs $18.99 once. Your AI client, model, or provider may charge separately. There is no PlugICT subscription, and no AI model subscription is included.

What are the system requirements?

Windows, macOS or Linux with Python 3.10+ and a supported agent. Setup installs its Python dependencies in an isolated environment.

Is this an official ICT product or a signal service?

No. PlugICT is an independent educational research tool, not affiliated with The Inner Circle Trader or Michael J. Huddleston. It is not financial advice or a trade signal service. AI answers can be wrong; verify them against the original lessons.
