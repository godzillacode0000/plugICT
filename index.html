Questions, answered.

Do I need to be technical to set this up? +

No. Tell your AI agent to install PlugICT, give setup the path to your private license.key, and let it run the doctor and direct-search checks. No MCP config is required for the default path.

Does it work without internet? +

The vault's search runs locally on your machine — it never sends your queries to a cloud. But your AI agent and the YouTube links do need internet. Think of it like this: the library is on your shelf, but you need wifi to ask the librarian.

Can I use it with my own AI agent? +

Yes — PlugICT is built for Hermes and similar terminal-capable agents that can run local Python commands and read JSON. The default path uses plugict_search.py; MCP is optional for compatible clients. A normal browser chat by itself cannot reach a local vault.

What exactly do I download? +

You get the public PlugICT GitHub repo and a private license.key delivered after purchase. Setup downloads and verifies the encrypted vault release automatically. No separate app or manual config hunting — and please don't share the license.

Do I need to pay for anything else? +

PlugICT itself is a one-time $18.99 purchase. The AI model is separate: you use your own supported client and provider, so any model cost depends on what you choose.

How can I pay? +

International cards via Stripe. Your license is delivered within 24 hours after purchase, and the product works exactly the same however you paid.

What are the system requirements? +

Windows, macOS or Linux with Python 3.10+. The setup script handles the rest in an isolated environment, so it won't interfere with anything else on your computer.
